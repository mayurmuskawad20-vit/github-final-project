
# Simple Interest Calculator

## Description
This project calculates simple interest using the principal amount, rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Inputs
- Principal: Initial amount of money
- Rate of Interest: Annual interest rate in percentage
- Time Period: Duration in years

## Example
Principal = 1000
Rate of Interest = 5%
Time Period = 2 years

Simple Interest = (1000 × 5 × 2) / 100 = 100

## Technology Used
- Bash scripting
